## 二、提炼出的 6 条可复用技法（已折叠进资产库）

1. **五类锚定矩阵**（来自《万物生》）：角色 / 场景 / 色卡 / 音色 / 故事板五类锚点在跨段时保持不变形——直接对应 S2 五份 manifest + S3 storyboard 的引用结构。
2. **双层 STYLE LOCK**：底层「胶片质感 / 角色固定描述」永不改（= `fixed_prompt`），上层「类型调性」每镜可换（= `style_variation` 字段）。统一但不单调。
3. **段间遮罩衔接**：纯黑 / 纯白 / 贴镜遮罩三种转场，把 10 秒片段连成一部片；写入 `template-library.json` 的 `transitions`。
4. **命名铁律法**：给每条约束 / 镜头起具体名字（如「大漠残兵色板」），AI 服从度翻倍；写入 `template-library.json` 的 `naming` 规则，与既有 movement/character id 命名一致。
5. **权力轴（高低角暗示强弱）**：仰拍=强势/威压，俯拍=弱势/交代；战力对峙优先低角拉特写 + 慢动作。写入 `scene-multiview.md` 与 `camera-movements.json`。
6. **冲突前置 / 黄金 3 秒**：Hook 节拍必须在前 3 秒呈现核心冲突（撞见出轨→黑化眼神→逆袭预告）；写入 `beat-sheet.md`。

## 三、来源质量说明（诚实标注）

- **权威可信**：thepaper.cn（行业数据）、qq.com《万物生》拆解、china.com.cn 查雨昕专访、Adobe / Freelance Video 的 shot-reverse-shot 理论页。
- **通用 / SEO 聚合**（jzjtgobo、meiguba、zlwq 等）：运镜参数是模板化的「行业常识」，当作通行做法参考，不视为某剧专属秘方。
- **横屏 vs 竖屏**：本技能定位 **横屏 16:9**，故「V 型垂直运镜 / 1+3 网格 / 9:16」等纯竖屏技法**不吸收**，仅吸收与横屏通用的（正反打、锚定矩阵、冲突前置、多机位三视图、波浪剪辑）。

# 剧本格式规范（原创整理）

> 用途：S1 改编剧本 Skill 的「剧本怎么写」格式基准。下文为行业通用剧本格式要素 + 一段公版素材自写表达范例，全部原创，不含任何受版权保护文本。

## 一、标准剧本格式要素

| 要素 | 写法 | 说明 |
|---|---|---|
| **场景标题 Slugline** | `INT. 卧室 - 夜晚` / `EXT. 花园 - 黄昏` | `INT./EXT.` 内外景；后接地点；再接时间（日/夜/晨/黄昏/连续） |
| **动作行 Action** | 客观描述可见画面，现在时 | 只写「能拍到的」，不写心理活动 |
| **人物名 Character** | 对白前全大写、居中 | 如 `小兔` |
| **对白 Dialogue** | 人物名下方 | 口语、短句；儿童向 / 低龄受众尤其要简单，漫剧可对白少、靠字幕与画面叙事 |
| **括号提示 Parenthetical** | `(轻声)` | 指导语气/动作，尽量少用 |
| **转场 Transition** | `切至：` / `淡出。` | 标注场景切换方式 |

## 二、原创范例（公版素材自写表达）

> 以下改编自公版戏剧《罗密欧与朱丽叶》的「阳台相会」核心事件，用现代简体中文原创重写表达，不复制原作文字。

```
EXT. 花园 - 夜晚

月光下，茱丽叶趴在二楼的石栏上，望着星空。

茱丽叶
（轻声）
要是名字不重要，该多好。

罗密欧从花丛后走出，抬头看她。

罗密欧
那你愿意，做我的朋友吗？

茱丽叶
（笑）
明天，让信鸽带话给我。

切至：

INT. 小屋 - 清晨

信鸽落在窗台。茱丽叶展开小纸条，眼睛亮了。

淡出。
```

## 三、与 S3 分镜的衔接

- 剧本每个「场景」→ S3 拆为若干 `shot`
- 每个 `shot` → 一条 Seedance 提示词（见 S3 `template_library.json` 的镜头类型模板）
- 剧本的「动作行」是提示词的主语来源；「人物名」对应 S2 角色一致性锚点

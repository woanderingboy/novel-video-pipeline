# 小说 → 短视频剧本 改编压缩方法论（原创）

## 一、五大原则

1. **单轴优先**：只保留一条情感/任务主线，支线砍掉或合并进主线。
2. **角色精简**：保留 2–3 个核心角色，配角功能化（一个推动、一个陪伴）。
3. **场景合并**：把原作多章浓缩为 3–6 个关键场景。
4. **画面代叙述**：用动作/视觉呈现，删除内心独白与长段描写。
5. **时长反推**：目标 90s → 约 5–8 个 shot，每 shot 8–15s。

## 二、操作流程

```
1. 读原作 → 提取「核心事件链」（3-6 个关键节点）
2. 定主线与价值落点（这部要教什么？）
3. 列场景节拍表（对齐《故事结构模板》的某一种）
4. 写剧本（按《剧本格式规范》）
5. 交 S3 拆 shot → 生成 Seedance 提示词
6. S2 提供风格/角色锚点，S4 提供 BGM/音效
```

## 三、压缩对照表（以 90s 短视频为例）

| 原作要素 | 改编处理 |
|---|---|
| 多章节铺垫 | 合并为 1 个「设定」shot |
| 心理描写 | 改为角色动作 + 一句旁白 |
| 支线人物 | 删除或合并到主角行动 |
| 长篇对话 | 保留 1–2 句关键对白 |
| 结局留白 | 改为明确正向价值收尾 |

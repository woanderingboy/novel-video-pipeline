## 通用铁律：冲突前置 / 黄金 3 秒（借鉴爆款短剧节奏）

- **黄金 3 秒**：前 3 秒必须出现强冲突 / 视觉奇观 / 悬念提问，否则观众划走。对应本表 **Hook 节拍（0–5s）**——核心冲突必须在前三帧落地（如「女主撞见渣男出轨 → 黑化眼神 → 逆袭预告」三连）。
- **冲突前置**：不要把冲突埋到第 20 秒以后。S1 改编时，钩子即冲突，爽点 / 反转随后密集铺排。
- **波浪式剪辑（节奏）**：每约 15 秒设置一个情绪峰，避免长平。S3 拆 shot 时据此安排动静交替与镜头时长。
- 注：横屏 16:9 漫剧可适度放宽前 3 秒的硬性，但 **Hook 必须一镜抓人**（见 `camera-movements.json` 的 Hook 运镜映射：dolly_in / crane_down / low_angle / reveal_from_behind）。

## 权力动态标注（可选 · 接 S2/S3 权力轴）

> 与 `assets/s2/scene-multiview.md` §三（补）「权力轴」联动：用机位高低标注人物权力关系，是叠加在正反打之上的**语义轴**。

在权力关系变化的节拍，额外标注 `power_dynamic`，交 S2/S3 落地：

| `power_dynamic` | 含义 | S3 落地（camera-movements.json） |
|---|---|---|
| `dominate` | 该角色此刻占上风 / 威压 | `low_angle` + `MCU/CU` |
| `submit` | 该角色此刻被压制 / 弱势 | `high_angle` + `MS` |
| `equal` | 势均力敌、平权 | 眼平 `ots` ↔ `ots_reverse`（不用高低角） |
| `shift` | 权力反转（由弱转强或反之） | 前 `high_angle` → 切 `low_angle` + `whip_pan` |

- 直接对应 `subject_aware_map` 的 `power_shift` 推荐运镜（`low_angle / high_angle / crane_up / tilt_up / slow_motion`）。
- S2 在 `scene_manifest` 的 `power_notes` / 视图 `default_power` 承接此标注；S3 在 `shot` 上用 `camera_movement` + `speed:"slow_motion"` 实现（详见 scene-multiview §三（补））。
- 仅**权力变化时刻**标注，平权对话不标，避免语义稀释。

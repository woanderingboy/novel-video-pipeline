# 改编范例：阳台相会（公版素材原创改编）

> 素材来源：莎士比亚《罗密欧与朱丽叶》属公版。以下为「核心事件 → 儿童向漫剧示例（90s）」的原创改写示范，展示如何套用结构模板与格式规范。作为可选子类型，启用时额外强制 IP 防火墙 + 排除 `mature`。

## 结构对齐（儿童向漫剧结构 · 故事结构模板 §5）

- Hook（0–5s）：花园里一只萤火虫飞起
- 设定（5–20s）：茱丽叶在窗边，罗密欧躲在花丛后
- 冲突（20–40s）：两家人不合，不能做朋友
- 尝试（40–90s）：罗密欧递上一朵小花；茱丽叶摇头又点头
- 转折（90–120s）：信鸽落下，带来和解的纸条
- 解决（120–150s）：两人约定明天在树下见面
- 价值收尾（150–180s）：「真正的朋友，不怕名字」

## 剧本（原创表达）

```
EXT. 花园 - 夜晚

一只萤火虫从草丛升起，照亮趴在窗边的茱丽叶。

罗密欧（画外）
你不怕被发现吗？

茱丽叶
（低头笑）
怕，可我还是想说话。

罗密欧从花丛后走出，递上一朵小蓝花。

罗密欧
这个，送你。

茱丽叶接过花，点点头，又摇摇头。

茱丽叶
我们两家人……不做朋友。

一只信鸽落在窗台，腿上绑着纸条。茱丽叶展开，眼睛亮了。

茱丽叶
（轻声）
明天，树下见。

切至：

EXT. 大树下 - 清晨

两个孩子并肩坐着，分享一颗果子。

淡出。
```

> 价值落点：**真正的朋友，不怕名字**（对应「勇气 / 接纳」教育主题）。

# 故事结构模板（方法层，不可版权）

> 说明：以下结构为叙事「方法 / 框架」。美国版权法只保护「表达」不保护「方法」，因此可自由使用、改编。所列书籍（如 *Save the Cat!*）仅供学习参考，**不抄原文**，仅取框架名。

## 1. 三幕式 Three-Act

- **第一幕 建置（0–25%）**：主角、世界、核心欲望
- **第二幕 对抗（25–75%）**：障碍出现、主角尝试、反复受挫
- **第三幕 解决（75–100%）**：高潮、结局、价值落点

## 3. 八序列法（8-Sequence）

序列 1 建置 → 序列 2 转折 → 序列 3 第一幕终点 → 序列 4 游戏上半 → 序列 5 中点 → 序列 6 游戏下半 → 序列 7 第二幕终点 → 序列 8 解决。长片每序列约 12–15 分钟；短视频按比例压缩。

## 4. 漫剧结构（横屏 16:9 · 多集连载，默认主结构）

漫剧 = 小说 / 网文 / 漫画改编的**横屏 16:9 动态短剧**，单集 1–3 分钟、多集连载，B站 / YouTube 向为主。核心引擎是**情绪钩子 + 爽点 + 反转 + 悬念**，每集结尾留续集钩子。产线基调对标当下爆款漫剧节奏，但**只取法其方法层骨架，角色 / 情节 / 画风一律原创**（见下方「爆款借鉴方法论」）。

**单集节拍（1–3 分钟 · 16:9 横屏）**：

| 段落 | 时间 | 作用 |
|---|---|---|
| **钩子 Hook** | 0–3s | 强冲突 / 悬念开场（如：被当众退婚、重生睁眼） |
| **铺垫 Setup** | 3–15s | 一句话交代身份 + 处境 + 目标 |
| **升阶 Stakes** | 15–40s | 压迫升级，主角陷入绝境 / 误会与羞辱 |
| **反转 Twist** | 40–75s | 金手指觉醒 / 身份揭晓 / 反杀铺垫 |
| **爽点 Payoff** | 75–120s | 逆袭打脸 / 高光名场面 |
| **悬念 Cliff** | 120–150s | 续集钩子（下集预告式收尾） |

> 多集连载时，每集的 Cliff 即下一集的 Hook，形成「集间钩子链」。长线用三幕式（§1）搭季弧，八序列法（§3）切大篇章。

### 4.1 横屏 16:9 构图提示

16:9 横屏与竖屏的镜头语言不同，分镜提示词需相应调整：

- **多用双人 / 过肩中景（medium two-shot / over-the-shoulder）** 承载对话与对峙，而非竖屏堆叠的特写。
- **利用纵深与左右空间**：前景人物 + 中景环境 + 背景纵深的「三明治」构图，强化电影感。
- **宽幅空镜与航拍（wide / aerial）** 用于转场、世界观铺陈、情绪留白，竖屏用得少、横屏是强项。
- **避免竖屏思维**：不要全程怼脸特写、不要把字幕堆在窄条里；横屏要给画面「呼吸的横向空间」。
- **比例闸门**：S3 `aspect_ratio` 必须 = `16:9`（bilibili 预设），否则门禁 warn / strict 失败。

### 4.2 爆款漫剧「借鉴方法论」（方法层可借鉴，表达不照搬）

> 用户意图：漫剧要对标当下爆火的作品。**可以借鉴，不要完全抄袭。**

可自由借鉴（不可版权，是创作养料）：

- **题材 / 类型钩子**：重生 / 逆袭 / 追妻火葬场 / 先婚后爱 / 战神归来 / 悬疑反转等「情绪赛道」。
- **情绪结构**：前 3 秒强钩子、中段压迫升级、反转爽点、集尾悬念的节奏模板。
- **爽点范式**：身份揭晓、金手指觉醒、打脸名场面、反杀铺垫的「爽感配方」。
- **镜头语言 / 节奏**：如何用小景别切换制造紧张、如何用留白拖悬念。

禁止完全抄袭（侵权边界）：

- 不得**逐角色照搬**某爆款的同名同设定人物（换皮也属高风险）。
- 不得**逐场复制**其名场面构图、标志性分镜序列。
- 不得**直接复刻**其招牌画风 / 标志性配色组合。
- 不得**搬运原文台词 / 剧情大纲**。

> 实操：点名某爆款时，先抽取其「可复用的方法骨架」（如「强宿命感的对峙开场 + 三集反转」），再填入**原创的角色、世界观、台词**，送图像 / 视频模型；IP 防火墙负向词仍守住真实第三方版权形象（Disney / Marvel 等）。

## 5. 儿童向漫剧结构（可选子类型，针对 3–8 岁 / 1–3 分钟）

| 段落 | 时间 | 作用 |
|---|---|---|
| **Hook 钩子** | 0–5s | 强视觉/声音抓住注意力 |
| **设定** | 5–20s | 一句话交代人物 + 场景 |
| **冲突** | 20–40s | 出现一个小问题 |
| **尝试** | 40–90s | 主角行动 2–3 次 |
| **转折** | 90–120s | 意外发现 / 获得帮助 |
| **解决** | 120–150s | 问题化解 |
| **价值收尾** | 150–180s | 一句正向价值（分享/勇敢/诚实） |

> 本结构为儿童教育内容原创设计，可直接用于「灵感童学工坊」类儿童向漫剧与游戏过场。启用时额外强制 IP 防火墙 + 排除 `mature`。

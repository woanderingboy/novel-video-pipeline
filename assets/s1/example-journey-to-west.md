# 改编范例：三打白骨精（公版素材原创改编 · 儿童向漫剧示例）

> 素材来源：《西游记》属公版。以下为「核心事件 → 儿童向漫剧示例（90s）」的原创改写，套用儿童向漫剧结构（§5），演示「神话 IP 去宗教化、转教育主题」。作为可选子类型，启用时额外强制 IP 防火墙 + 排除 `mature`。

## 结构对齐（儿童向漫剧结构 · 故事结构模板 §5）

- Hook（0–5s）：山里飘来一阵妖风
- 设定（5–20s）：唐僧师徒四人路过荒山
- 冲突（20–40s）：白骨精变村姑想骗人
- 尝试（40–90s）：悟空三次识破、打跑妖怪；八戒却说悟空乱来
- 转折（90–120s）：师傅生气赶走悟空，妖怪趁机掳走师傅
- 解决（120–150s）：悟空悄悄回来救出师傅
- 价值收尾（150–180s）：「真正的聪明，是看清真相也不丢善良」

## 剧本（原创表达）

```
EXT. 荒山 - 日

一阵妖风卷过枯树。唐僧擦汗，徒弟们跟在身后。

白骨精（画外，变作村姑）
几位师父，喝碗汤吧？

悟空火眼金睛一闪，举起金箍棒。

悟空
妖怪！现形！

村姑化作白烟逃走。八戒撇嘴。

八戒
大师兄，你又吓唬人。

白骨精连变两次，都被悟空打跑。唐僧摇头。

唐僧
你太凶了，走吧。

悟空含泪一个筋斗离去。夜里，妖风再起，掳走了唐僧。

悟空的身影从云中落下，一棒砸开山洞。

悟空
师傅，我回来啦。

切至：

EXT. 山道 - 晨

师徒重聚。唐僧愧疚地拍拍悟空。

淡出。
```

> 价值落点：**真正的聪明，是看清真相也不丢善良**（对应「分辨 / 宽容」教育主题）。
> 注意：公版故事核可用；但「孙悟空」形象若走商业发行，建议用原创角色名/造型规避商标争议（配合 S2 负向词库双保险）。
